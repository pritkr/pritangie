## Section F — Method, caveats, and how to re-run the scan

**How this list was produced**
1. `scan.py` — pulls LinkedIn's public jobs API (`jobs-guest/.../seeMoreJobPostings`, 19 keyword/filter combos), Internshala work-from-home + part-time category pages, and Unstop's public opportunity API.
2. `boards.py` — pulls Ashby + Greenhouse public boards for 27 OSS/privacy-first employers and filters for intern/entry titles.
3. `rank.py` — scores every row (tech-keyword match, remote flag, paid stipend, known-good company; penalises marketing/sales/HR/unpaid).
4. `shortlist.py` — renders the ranked tables into `leads-shortlist.md`.

Re-run anytime (~3 minutes):
```bash
cd job-hunt && python3 scan.py && python3 rank.py && python3 shortlist.py && python3 boards.py
```
(Requires `curl`, `python3`, `beautifulsoup4`, `lxml` — all already present on this machine.)

**Caveats — read before you trust a row blindly**
- **Your Brave was not automated.** I attached agent-browser to it (the old `brave-shop` session listed your tabs, incl. your logged-in LinkedIn search), but Brave rejected the CDP websocket handshake, so instead of touching your browser I used login-free public APIs. Nothing in your browser was changed, and no applications were submitted.
- **LinkedIn ignores the part-time filter** on the public API: 90 of its "part-time" rows were actually senior full-time jobs (Siemens, JPMorgan, Mastercard…). Those were dropped.
- **LinkedIn's remote flag is unreliable** in the public API too — always open the posting and check the workplace type before investing time.
- Internshala/Unstop rows reflect the listings as of 24 Sep 2026; NGO postings are frequently unpaid, which the ranking penalises.
- The Ente DevRel part-time role and a few FOSS United entries are older postings — confirm they're still open before writing a long application.

**Suggested order of operations**
1. Today: fix LinkedIn "Open to work" + headline; apply to rows 1–4 of Section A; open a tab for every Section B link.
2. This week: start the Frappe PR path (B1), and DM the Tattle + Pinaca + Zingg contacts via the FOSS United postings.
3. This month: apply to Canonical + Supabase APAC; set alerts on Brave/Proton/Tailscale; join the C4GT community program so you're a known name before the April 2027 window.
4. Nov–Jan: pick your GSoC 2027 orgs and get PRs merged so February is a formality.
